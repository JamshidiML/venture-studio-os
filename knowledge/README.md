# Knowledge

This directory captures reusable learning from completed research, validation, product, engineering, and governance cycles. Knowledge artifacts summarize patterns and link their source evidence; they do not retroactively change decisions or promote low-confidence observations into facts.

Useful content includes falsified assumptions, experiment design lessons, distribution or customer-research methods, reusable technical patterns, failure modes, and decision-quality retrospectives. Remove unnecessary personal or confidential data and preserve source limitations.

Each entry records date, owner, source artifact paths and versions, applicable context, confidence, limitations, and reuse guidance. Any new action inspired by a lesson still requires an approved issue and the appropriate stage gate.
