# T10 Search Log

## Method

Searches were executed on 2026-07-22. Primary technical documentation, original work-task studies, independent evaluation research, academic synthesis, and government regulation/risk guidance were prioritized. Candidate generation began only after capability and limitation evidence was recorded.

| Sequence | Query or direct lookup | Purpose | Result/disposition |
|---:|---|---|---|
| 1 | `site:ilo.org generative AI jobs tasks 2025 report augmentation` | Independent occupational/task evidence | Retained ILO task-exposure index and transformation conclusion. |
| 2 | `site:anthropic.com research Economic Index AI tasks 2026` | Current observed AI-use patterns | Retained January and June 2026 reports with provider limitation. |
| 3 | `site:openai.com/index GDPval professional tasks benchmark 2025` | Realistic professional deliverable evidence | Retained GDPval scope, expert-grading method, and one-shot limitations. |
| 4 | `site:hai.stanford.edu AI Index Report 2026 technical performance` | Cross-model capability synthesis | Retained technical and responsible-AI chapters. |

| 6 | `site:metr.org AI task completion time horizon 2026` | Independent agent reliability evidence | Retained current time-horizon research; limited to software tasks. |
| 7 | `site:ai.google.dev Gemini document processing official PDF` | Current multimodal document capability | Retained official document-understanding guide and explicit limits. |
| 8 | `site:developers.openai.com models vision multilingual tools official` | Current model/tool availability | Retained official models catalog without relying on prices. |
| 9 | `site:digital-strategy.ec.europa.eu AI Act general purpose AI obligations` | Current EU requirements | Retained official obligations and dates. |
| 10 | Cross-domain candidate queries for archives, research evidence, records, schemas, standards, and provenance | Concrete jobs outside T01–T09 | Used only to generate hypotheses; no weak blog or vendor list was admitted as demand evidence. |

## Rejected evidence classes

- SEO market-size pages, vendor total-addressable-market claims, affiliate lists, unsourced adoption charts, and social-media anecdotes.
- Provider benchmark headline without method or limitation.
- API availability inferred from memory rather than current official documentation.
- “AI can automate X” statements lacking task boundary, evaluation, human authority, or fallback.

## Negative findings

- No current primary source in this pass establishes willingness to pay for any listed candidate.
- No candidate-specific production benchmark, error distribution, latency, or unit cost was located or executed.
- No defensibility claim is supported beyond a hypothesis about workflow-specific data, evaluation, and correction history.

## Reproducibility ceiling

This is a broad Gate 1 search, not a systematic review. Search indexes and model/API documentation change. Later work must snapshot exact model versions, inputs, evaluation sets, and costs under separate authorization.
