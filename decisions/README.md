# Decisions

This directory stores authoritative Founder gate and investment decisions. Decision records identify the reviewed artifact versions, rationale, evidence confidence, blockers, accepted risks, conditions, and exact next authorized action.

Use ISO-dated paths and stable opportunity IDs, for example `decisions/OPP-YYYY-NNN/YYYY-MM-DD-investment-decision.md`. Investment decisions use [`templates/INVESTMENT_DECISION.md`](../templates/INVESTMENT_DECISION.md).

Approved records are not silently rewritten. If evidence changes the decision, create a new record and mark the prior artifact `superseded` with a link to its replacement. Chat messages, merged code, and Governance recommendations do not replace a Founder decision record.
