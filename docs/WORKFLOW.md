# Venture Studio Workflow

## Principle

No product progresses because a document exists. It progresses only when evidence satisfies an explicit gate.

## Lifecycle

### Gate 0 — System readiness
Required: roles, evidence rules, scoring model, artifact standards, and decision authority.

### Gate 1 — Market discovery
Create a broad, evidence-backed opportunity universe. Exclude products that are legally unsafe, dependent on unauthorized copying, dominated by prohibitive network effects, or infeasible for a lean team.

### Gate 2 — Opportunity screening
Rank candidates using problem severity, frequency, willingness to pay, market accessibility, competitive gap, buildability, AI leverage, distribution feasibility, founder fit, and portfolio reuse.

### Gate 3 — Deep due diligence
Test customer pain, alternatives, moat, economics, technical feasibility, legal constraints, differentiation, acquisition path, and failure modes.

### Gate 4 — Investment decision
Decision must be one of: `GO`, `HOLD`, `PIVOT`, or `NO-GO`. Record rationale, evidence, confidence, unresolved risks, and kill criteria.

### Gate 5 — Validation
Run the smallest experiments that can falsify the core assumptions. Do not build the full MVP before validating problem, audience, value proposition, and willingness to pay.

### Gate 6 — Product definition
Create approved PRD, MVP scope, architecture decisions, data/privacy requirements, acceptance criteria, and delivery plan.

### Gate 7 — Engineering execution
Codex works only from approved issues and artifacts. Each milestone requires tests, documentation, and a pull request.

### Gate 8 — Governance and release
An independent review checks business alignment, architecture, security, privacy, testing, operability, and release readiness.

### Gate 9 — Learning loop
Capture results, failed assumptions, reusable assets, customer evidence, technical patterns, and decision quality.

## Status vocabulary

- `draft` — incomplete and non-authoritative
- `in-review` — awaiting independent review
- `approved` — accepted as current source of truth
- `superseded` — replaced by a newer artifact
- `deprecated` — retained only for history

## Non-negotiable rules

1. Claims must distinguish evidence, inference, assumption, and hypothesis.
2. Sources and dates must be recorded for market facts.
3. A Governance Agent may challenge but not silently rewrite Strategy artifacts.
4. Codex may not expand product scope without an approved change.
5. The Founder retains final decision authority.
